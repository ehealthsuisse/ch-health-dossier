This page contains a table listing all the free-text conformance statements found in this implementation guide. Each
statement has a stable identifier and is assigned to the actor(s) it applies to. The table is provided as a summary for
implementers to evaluate key features and to support testing (e.g. test coverage of test tools and simulators). However,
reading this table alone is insufficient to understand or successfully implement the specification:

1. The table only includes the conformance expectations expressed as free text in this implementation guide. It does not
   include the computable expectations represented in capability statements, profiles, value sets, etc., nor the
   requirements of the underlying IHE profiles.
2. The table only includes the 'formal' requirement. It does not provide the contextual language around the statement
   that is needed to understand it. The id of each statement is a hyperlink to the place where it appears in the text.

A few other notes:

* The ids are generally specific to the pages on which the requirements appear, but not always. If content is moved from
  one page to another, the id remains the same.
* While ids start as contiguous, conformance statements may be removed as the specification is updated, which creates
  gaps in the numbering. This is not an error.
* Ids are not final until published in an official release. After that point, ids will not be changed.
* The text of a statement may change from one release to another as long as its intent is the same. If the intent changes
  significantly, the old statement is removed and a new one with a new id is added.
* The statements are expressed against actors that represent logical entities, e.g.
  [PIXm Patient Identity Source](ActorDefinition-ch-pixm-source.html) and
  [PIXm Patient Identifier Cross-reference Manager](ActorDefinition-ch-pixm-manager.html). How these map to real
  systems depends on the implementation.

The conformance statements are also available as a computable
[Requirements resource](Requirements-fromNarrative.html) (represented in FHIR R4 as a Basic resource).

Currently only the statements of [Patient Identity Feed FHIR [ITI-104]](iti-104.html) are marked.
